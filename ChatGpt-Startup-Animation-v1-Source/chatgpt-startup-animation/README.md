# ChatGpt Startup Animation v1

Windows 桌面软件的自定义启动动画。动画会全屏播放，同时后台打开你选择的软件。窗口就绪后，片头会切换到软件。可用于 ChatGPT 和其他 Windows 软件。

这是独立项目，与 OpenAI 无隶属关系。

## 使用

1. 解压 Windows 发布包，双击 `ChatGpt Startup Animation.exe`。
2. 选择桌面上已有的软件快捷方式（.lnk）。可以修改欢迎标题、欢迎语和背景图。
3. 点「套用到原快捷方式」，双击原来的桌面图标即可播放。按 `Esc` 可以跳过片头。
4. 要撤销时，打开同目录的 `撤销片头.exe`，选择一个入口，再点「撤销所选」。

也可以选择软件的程序文件来新建桌面入口。详情见 [使用说明](使用说明.txt)。

## 从源码构建

在 Windows 的 PowerShell 中，从源码根目录运行：

```powershell
.\Build.ps1
```

脚本调用 Windows 上的 .NET Framework C# 编译器，在 `dist` 生成可分享的 ZIP。播放全屏片头时需要本机安装 Microsoft Edge 或 Google Chrome。

## 项目结构

- `src/` 包含 WinForms 设置界面、快捷方式备份与恢复、窗口识别和交接。
- `web/` 包含全屏动画、欢迎页和为片头生成的默认插画 `pearl.webp`。
- `Build.ps1` 将源码和网页资源打包成可运行的 Windows 发布包。

动画由绑定到回环地址的本机服务提供。每个套用后的快捷方式都有独立的欢迎页配置和本机备份。

通用版以可见且有响应的主窗口为切换条件。通过启动器打开的软件，可以填写窗口标题关键词辅助匹配。各软件内部的登录或加载画面需要按实际情况适配。
